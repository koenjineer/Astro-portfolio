# カンプからの素材の書き出し

Figmaのカンプから写真や飾りを書き出すときの決まりごと。
`minami-dental-next`（2026-09、全7ページ）で**繰り返し同じ判断をしたもの**だけを書く。

## 素材は元の解像度を超えて引き伸ばさない

**Figmaの書き出し倍率をうのみにしない。** カンプの設定のままだと、元の写真より大きく
書き出されることがある（ファーストビューが2倍設定で、元は横1920pxしか無かった例がある）。

- 倍率は**自分で決める**（PC 1.5倍・SP 2倍を既定にした）
- 元が小さい写真は、**枠に写る範囲の元画素数を測り、それを超えない倍率**まで下げる。
  他の写真より小さくなるが、縦横比が同じなら表示時に引き伸ばす量が変わるだけ
- 表示側でも同じ。1列表示で写真が伸びるなら**元の幅で止める**（630pxの写真は630pxで止めた）
- 写真はjpgで書き出して `cwebp -q 90` でwebpにする。**文字の絵（表・図）は可逆のwebp**
- 飾りのSVGは、通常の書き出しだとキャンバスの背景や親フレームの枠まで入る。**図形だけの版**で書き出す
