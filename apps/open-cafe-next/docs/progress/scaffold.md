`apps/minami-dental-next` の設定をそのまま複製し（Next 16.3.3 / React 19.2.8 / Tailwind v4）、
データ取得の部品と疎通確認用の仮ページまで作った。ページ・ヘッダー・色・フォントはまだ無い。

- `lib/images.ts`：アイキャッチとACF画像の両方に使えるよう、型を `ImageConnection` にした。
  代わりの画像を持つ引数はやめ、画像が無ければ `null` を返す形にした（代わりの画像はまだ無いため）
- `lib/queries/`：news / menu / products / shops / top。WPの形を画面で使う形に変えて返し、`cache` で包む
- `app/page.tsx`：仮ページ。お知らせ15・カテゴリー4・メニュー29・ジャンル7・ギフト9・店舗3・ランチ4
- CIのmatrixに `open-cafe-next` を追加、`.claude/launch.json` にport 3002で追加

計画から変えたこと（実データを見て）：

- **お知らせ・メニューは、アイキャッチが無くてもビルドを止めない。** お知らせは5件（営業時間の4件＋post-03）、
  メニューはドリンク14品に最初から画像が無く、止めるとビルドが通らないため。`null` で返す
- お知らせは**カテゴリーが無いとビルドを止める**（カテゴリ別一覧に置けなくなるため）
- ギフトは価格が無いと止める。メニューの価格は全件 `null` なので止めない
