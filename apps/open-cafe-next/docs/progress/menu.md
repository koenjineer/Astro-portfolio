# 2026-09-16 メニュー（ブランチ `feat/open-cafe-menu`）

`/menu/`（一覧）と `/genre/{slug}/`（ジャンル別）の2ページを1ブランチでまとめて作った。
タブ・料理のカード・ドリンクの表を2ページで共有するため。

## Figma・ユーザー決定で確定したこと（`docs/progress.md` の未決事項だったもの）

- **ページ送りは無し**。一覧は料理15品＋ドリンクの表、ジャンル別は最大でもドリンクの14品
- **価格はWordPressに入力した**（29品。Figmaと一致を確認）。価格が `null` の品があるとビルドが止まる
- **並びは管理画面の並び替え（menu_order）**（ユーザー決定。最初は投稿日順の予定だった）。
  menu_order はFigmaの並び（パスタ5→サラダ5→パン&スイーツ5→コーヒー6→紅茶3→ソフトドリンク5）に振り直し済み
- **ジャンルの並びはTERM_ID順**でFigmaのタブ（パスタ→サラダ→パン&スイーツ→ドリンク）と、
  ドリンクの表（コーヒー→紅茶→ソフトドリンク）の両方と一致した

## プラグイン「Post Types Order」と menu_order

WordPressに「Post Types Order」が入っていて、自動並び替え（autosort）が有効。
**GraphQLの `orderby` に何を書いても menu_order 順に上書きされる**（DATEやSLUGを指定しても効かない）。
クエリには意図が読めるよう `orderby: {field: MENU_ORDER, order: ASC}` と書いた。
GraphQLの `menuOrder` フィールドは、この投稿タイプ（`dish`）では取れない。詳細は `docs/wordpress.md`。

## 決めたこと

- **一覧の料理は、ジャンルの区切りなしで1つの並び**（Figmaが見出しなしで15枚を4列に並べている）
- **ドリンクだけ表にする判断は、親ジャンルのslug `drink` で行う**（`lib/queries/menu.ts` の `DRINK_GENRE_SLUG`）。
  ドリンクの品は親子両方のジャンルが付くので、子ジャンル（コーヒー等）で表を分ける。子ジャンルが無いドリンクはビルドを止める
- **料理の写真は必須**（`requireExistingLocalImageSrc`）。ドリンクは写真なし
- **`/genre/` は親ジャンル4つだけ書き出す**（`dynamicParams = false`）。コーヒー等のページはFigmaに無い
- ジャンル別のメタデータの題はジャンル名（「パスタ | OPEN CAFE」。お知らせのカテゴリ別の「… | お知らせ」形式にはそろえない：ユーザー決定）。上部の見出しは一覧と同じ「メニュー」
- ドロワーの現在地：`/genre/` でも「メニュー」を現在地にする（`lib/site.ts` の `EXTRA_NAV_PREFIXES`）
- **タブの現在地とホバーは同じ見た目**（ルールセットの variant 名が「カレント/ホバー」）。
  見た目の切り替えも `aria-current` で行い、状態を1か所で持つ
- 品名は料理のカードでは h2、ドリンクは表の見出し（コーヒー等）が h2 で、品名と価格は `dl`
- ドリンクの写真は固定の写真なので alt に短い説明を書いた（WPから来る料理の写真は `alt=""`）
- **タブの線・表の見出しの下線**：Figmaの線は寸法を増やさない。タブの白線は枠の4px内側に絶対配置、
  見出しの下余白は6pxから線の1pxを引いた5px

## カンプに無い幅（768〜1279px）

| 中身の幅 | タブ | カード | ドリンク |
|---|---|---|---|
| 375 | 2×2（160×64） | 2列 158px | 縦積み・写真なし（表295px） |
| 768 | 横1列で等分（172×69） | 4列 152px | 横3列（211px）・写真なし |
| 1024 | 横1列 200×69 | 4列 216px | 写真257px＋表687px |
| 1280 | 横1列 200×69 | 4列 245px | 写真327px＋表687px |

- **タブの200px固定は `lg` から。** 4つで842px要り、768px（中身728px）でははみ出した（実測で横スクロールが出た）
- **ドリンクの写真は `lg` から。** 写真327＋表687＝1014pxが768pxに入らない。1024〜1279pxは写真だけ縮める
- カードはギフトと同じく `md` から4列（768pxで152px。SPの158pxとほぼ同じなので読みにくくならない）
