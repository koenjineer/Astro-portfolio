# 2026-09-16 店舗情報（ブランチ `feat/open-cafe-shop`）

`/shop/` を作った。WPの `shops` 3店舗を「見出し＋店内の写真＋店舗情報の表」で縦に並べる。
3ページ目なので、先に**見た目を変えない共通化**を済ませてからページを作った。

- `components/layout/SubPageLayout.tsx`：main＋上部の写真＋パンくず＋本文の余白（`px-5 pt-[60px] pb-40 md:pt-20`）。
  products と contact で完全に同じだった。本文の幅の上限（1100 / 688px）はページごとに違うので持たせない
- `components/shop/ShopInfoList.tsx`：住所・TELなどの表。フッターと寸法・並び・順序が一致するので共有する

決めたこと：

- **並び順は `lib/site.ts` の `SHOP_TITLE_ORDER`（店名の配列）で固定**（ユーザー決定）。WPの登録日順も
  偶然Figmaと同じだが、管理画面で登録し直すと崩れるため。配列に無い店名は末尾に回す。
  **全角スペースまで完全一致させること**（ずれてもエラーにならず、並びだけが静かに崩れる）
- **フッターの店舗情報は `lib/site.ts` の直書きのまま**（ユーザー決定）。フッターは全ページに出るので、
  WPの取得失敗で全ページが落ちる形にしない。共有するのは見た目の部品だけ
- **店舗のアイキャッチは「店内の写真」**。ファイル名が `map_*` なのは登録時の名残で、中身は地図ではない
- **画像はWPの原本をそのまま置いた**（1032×566＝Figmaの1.5倍）。webpを書き出し直すと二重に圧縮されるため。
  WPがどの店にどの画像かを持っているので、写真の取り違えも起きない
- **`requireExistingLocalImageSrc` を店舗にも効かせた**（ギフトに続いて2つ目）
- 見出しの縦棒は6px。Figmaの線は寸法を増やさないので、左余白はFigmaの16pxから棒の6pxを引いた10pxにする
