# 2026-09-16 ギフト・贈り物（ブランチ `feat/open-cafe-products`）

`/products/` を作った。WPの `products` 9件を、1件目だけ大カード（PC 2列×2行、SP 1行）で並べ、下にラッピング案内。

計画から変えたこと・決めたこと：

- **並び順は投稿日時の古い順**（`DATE ASC`）。Figmaの並びと完全に一致するので、配列で持たない
- **「ショップで確認する」は押せるリンク**（ユーザー決定）。行き先が無いので `/products/` ＋ `scroll={false}`（押してもURL・スクロール位置が変わらないことを確認）。
  9個とも同じ文言なので `sr-only` で商品名を添えた
- **ボタンのホバーはルールセットのショップカードボタン（白地＋main色の文字）**。当初の計画の透明度70%は誤り。
  枠線1pxを常に付け、padding をFigmaから1px減らして高さをPC 37px / SP 30pxに保つ
- **ボタンをPCの寸法（幅174px）に切り替える幅は `lg`**（大・小カードとも）。768pxでは小カードが148pxしかなく、`md` で切り替えると文字が2行に折り返したため。
  768〜1023pxはSPの寸法（幅132px・高さ30px）で、`whitespace-nowrap` も付けた。
  実測：小カード 768px 148 / 900px 181 / 1023px 212 / 1024px 212（ボタン174）/ 1280px 245。375〜1280pxの6幅ともボタン1行・カード内・横スクロール無し
- **商品写真の alt は空**（計画は商品名）。WPから来る写真は飾り扱いの決まり（`/rules/headless-wordpress.md`）で、商品名は直下の h2 が伝え、alt に入れると読み上げで2回続くため
- **本文の下余白は160px**（計画はPC80/SP60だったが、Figmaの main は下160px。これで main の高さがFigmaと一致する）
- **ラッピング案内の枠の padding はFigmaから4px引いた値**（PC 56/75、SP 36）。Figmaの枠線は内側に描かれて寸法を増やさないため
- **点線のSVGは、書き出しに付く `preserveAspectRatio="none"` 等の外側の属性を外した**（図形は書き出しのまま）。
  付けたまま11px幅のタイルにすると点が横に伸びて楕円になるため。点は11pxタイルの中央に描かれるので、PCは位置を−4px、SPは `space` で左右に4pxはみ出させて端にそろえる
- **商品画像がpublic/に無いとビルドを止める**（`lib/images.server.ts` の `requireExistingLocalImageSrc`）。ギフトだけに効かせた。
  TOPのランチは画像がまだリポジトリに無く、仮ページ `app/page.tsx` が読むため。**TOPを作るときに同じ確認に切り替える**（店舗は切り替え済み）
- 商品写真はFigma「【ギフト】サムネイル画像」から1.5倍（792px）。シフォンケーキはレイヤー名が `img_item3` と誤っているので `img_item33.webp` にした。9枚ともWPの原本と見比べて一致
- ラッピングの写真は2倍（920×600、元1920×1280）。縦並びのタブレット幅で横888pxまで広がるため

### ラッピング案内を横並びにする幅：`lg`（1024px）

実測（ヘッドレスChrome、中身の幅はスクロールバー15pxを引いた値）：

| 画面幅 | 組み | 見出しの行数（1行の長さ） | 本文1行の最長 |
|---|---|---|---|
| 375 | 縦 | 2行（239px、折り返し任せ） | 252px |
| 768 | 縦 | 2行（429 / 288px） | 623px |
| 1023 | 縦 | 2行 | 766px |
| 1024 | 横（1列395px） | **3行**（383 / 46 / 288px。「す。」が1行に残る） | 383px |
| 1280 | 横（1列460px） | 2行（Figmaどおり） | 447px |

- `xl` にすると1024〜1279pxが縦並びになり、本文1行が766pxから最大1020pxまで伸びる。見出しの3行より読みにくいので `lg` にした
- 見出しが2行に収まるのは、1列が432px以上になる中身の幅約1085px以上
- 1024〜約1085pxでラッピング案内の見出しの「す。」だけが3行目に残るが、Figmaに無い幅なのでそのままにした（ユーザー決定）
